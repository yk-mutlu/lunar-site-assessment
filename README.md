An advanced, interactive 3D WebGL aerospace platform designed for **Lunar Landing Site Selection**, **Spacecraft Trajectory Dynamics**, **Real-Time ROS 2 Telemetry Ingestion**, and an **End-to-End Artemis / Apollo 5-Stage Mission Simulation**.

Built with **Next.js 15**, **Three.js**, **React 19**, and **Zustand**, the simulator features real-world topographic elevation mathematics based on LRO (Lunar Reconnaissance Orbiter) data, Melosh crater morphology, autonomous rover obstacle avoidance, and hypersonic atmospheric return physics.

## 🚀 Key Capabilities & Mission Architecture

```
[ Stage 1: Earth Launch ] ➔ [ Stage 2: Lunar Orbit & Site Pick ] ➔ [ Stage 3: Powered Descent ]
                                                                                │
                                                                                ▼
[ Stage 5: Earth Return & Splashdown ] 🠔 [ Stage 4: Surface Traverse & Science ]
```

### 1. 🚀 Stage 1: Earth Launch & Ascent (`Stage1EarthLaunchView`)
- **Vehicles**: Space Launch System (SLS Block 1), Saturn V, Falcon Heavy, Starship, or user-customized rocket engines.
- **Flight Dynamics**: 3D ascent from Kennedy Space Center LC-39B with gravity turn program, staging sequence, Solid Rocket Booster (SRB) jettison, Max-Q atmospheric stresses, and orbital insertion HUD telemetry.
- **OpenRocket Integration**: Custom rocket editor and flight profile analyzer (apogee, burn-out velocity, thrust curves, propellant mass fraction).

### 2. 🛰️ Stage 2: Lunar Orbital Reconnaissance & Site Assessment (`ThreeOrbitMissionPreview`)
- **Ephemeris & Illumination**: Real-time solar vector modeling showing dynamic shadow lines across lunar craters and Permanently Shadowed Regions (PSRs).
- **Cartographic Workstation**: Interactive 2D Leaflet Moon map and 3D lunar globe featuring LRO WAC (Wide Angle Camera) and NAC tile overlays.
- **Site Evaluation Engine**: Autonomous landing zone suitability analysis evaluating slope constraints ($\le 8.0^\circ$), crater density, boulder hazards, earth visibility, and solar power persistence.

### 3. 🦅 Stage 3: Powered Lunar Descent & Touchdown (`Stage3LunarDescentView`)
- **Lander Simulation**: Altair / Apollo LEM class lander with RCS attitude thrusters, main braking engine plume, and landing leg shock absorption.
- **Regolith Plume Dynamics**: Soft radial dust-cloud simulation generated by engine exhaust impingement on lunar soil (high-velocity particles dispersing outward from the landing pad).
- **Crater Elevation Alignment**: Mathematical crater topography model guaranteeing smooth touchdown at $(0,0,0)$ elevation while showcasing surrounding crater rims and shadow depths.

### 4. 🚜 Stage 4: Surface Traverse & Science Operations (`Stage4SurfaceTraverseView`)
- **Autonomous Rover Mobility**: 4-wheel rover traversing the lunar plain along a designated straight corridor with active wheel-to-ground height clamping.
- **Dynamic LiDAR Avoidance**: Active safety envelope detecting boulder fields and preventing the rover from sliding into steep crater basins.
- **NASA CRaTER Space Weather Model**: Live cosmic ray telemetry (Galactic Cosmic Rays dose rate, solar proton flux, solar wind velocity, and single-event upset hazard calculation).
- **Geological Waypoints**:
  1. *Lander Touchdown Base*
  2. *Basalt Plains & Regolith Core Sampling* (High-titanium basalt and ilmenite)
  3. *PSR Cold Trap* (Subsurface water ice deposits)
  4. *High Solar & Comm Ridge* (Continuous line-of-sight communication with Earth)

### 5. 🌊 Stage 5: Earth Return & Pacific Splashdown (`Stage5LunarReturnView`)
- **4-Phase Cinematic Sequence**:
  - **Phase 1 (Lunar Ascent)**: Ascent stage ignites and lifts off into orbit, leaving the descent stage platform on the moon surface.
  - **Phase 2 (Trans-Earth Coast)**: Deep space trans-Earth trajectory with high-resolution 3D Earth, lunar horizon, and starry void.
  - **Phase 3 (Hypersonic Reentry)**: Extreme atmospheric compression creating a glowing plasma fireball, flame particles, and ionization wake.
  - **Phase 4 (Parachute & Splashdown)**: Orange-and-white ring-sail parachutes deploy, decelerating the conical capsule onto the Pacific Ocean with harmonic rolling waves, ocean spray, and buoyancy bobbing.
- **OrbitControls**: Full 360° mouse camera rotation, pan, and zoom enabled across every return phase.

## ⚙️ Installation & Setup

### Prerequisites
- **Node.js**: v18.18+ or v20+ recommended
- **npm** or **pnpm** or **yarn**
- *(Optional)* **ROS 2** with `rosbridge_server` for live hardware telemetry
- *(Optional)* **Ollama** running locally (`http://127.0.0.1:11434`) for AI advisor

### 1. Clone & Install
```bash
git clone https://github.com/your-username/lunar-site-assessment.git
cd lunar-site-assessment

# Install dependencies
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🛰️ ROS 2 Hardware Connection & Standalone Mode

Upon launching the application, a **ROS 2 Connection Modal** will prompt for bridge connectivity:

- **Connect via ROS 2 Bridge**:
  ```bash
  # In your ROS 2 environment (Humble/Iron):
  ros2 launch rosbridge_server rosbridge_websocket_launch.xml
  ```
  Enter WebSocket URL: `ws://localhost:9090` (or your robot's IP).
- **Standalone Simulation Mode**:
  If no hardware is connected, click **"Continue with Simulation"** to launch the autonomous high-fidelity physics simulator.

## 🔬 Scientific & Topographic Modeling

### Unified Lunar Elevation Model
The surface is generated via analytical crater mathematics (`src/data/lunar-surface-height.ts`):
- **Impact Crater Function**:
  $$z_{\text{crater}}(r) = -D \cdot \left(1 - \left(\frac{r}{R}\right)^2\right) + h_{\text{rim}} \cdot \exp\left(-\frac{(r - R)^2}{2 \sigma_{\text{rim}}^2}\right)$$
- **Guaranteed Landing Pad**: At $(0,0)$, the elevation and slope are normalized to $0.000\,\text{m}$ and $0.0^\circ$ for deterministic landing leg physics.
- **Albedo Ejecta Brightness**: Radial rays and rim crests exhibit high-albedo anorthosite reflectance, contrasting with the dark basalt floor.

### Real-Time Ocean Wave Simulation
Stage 5's Pacific splashdown renders procedural Gerstner-like multi-octave water displacement:
- Dynamic sun specular reflections on crests.
- Capsule buoyancy physics synchronized with wave peaks and troughs.
